# Testes JavaFX

`FxSmoke.java` carrega os FXML, inicia Desktop, Bar e Cozinha, autentica com as contas efêmeras e navega pelos módulos. Envia um pedido misto ao broker, aciona os controles de estação e verifica a consolidação no Backend e o arquivo de impressão gerado pelo terminal. Rode o [runner de integração](../README.md) com `-JavaFX` para obter também as capturas das telas.
