# Teste ponta a ponta

`Run-Integration.ps1` cria o banco de teste, inicia um Mosquitto com ACL, sobe o Backend em portas isoladas e executa `RestauranteIT.java`. Use os parâmetros `-JavaFX` e `-AndroidSerial` para incluir as interfaces. Pré-requisitos e cenários estão no [guia de testes](../README.md).
