# Testes MQTT

O runner de integração usa Eclipse Mosquitto real, clientes Eclipse Paho, QoS 1, ACL individual e reconexão com sessão persistente. A cobertura inclui publicação, despacho, confirmação, mensagens inválidas, duplicadas ou atrasadas e recuperação da fila. Veja [Validação](../README.md) e o [contrato MQTT](../../00%20-%20Documentacao%20Geral/Arquitetura/MQTT.md).
