# Impressão

Projeto Java SE para abrir no BlueJ. Compile as classes em `atlas.impressao`. Na execução integrada use o Terminal Cozinha, que fornece os trabalhos via API e registra seus resultados. A interface `Printer` tem os adaptadores de arquivo simulado e Java Print Service.

O Backend persiste os trabalhos e seu histórico no PostgreSQL. Leia o [manual da impressora](../00%20-%20Documentacao%20Geral/Manuais/Impressora.md) para configurar fila, papel e recuperação.
