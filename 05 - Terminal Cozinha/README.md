# Terminal da Cozinha

Na raiz, execute `Build.ps1` e `& '.\07 - Infraestrutura\Scripts\Run.ps1' -Module Cozinha`. Use conta COZINHA e credencial MQTT do mesmo código. A aplicação busca pedidos e trabalhos no Backend e assume a impressão no computador local.

Abra esta pasta no BlueJ. Ponto de entrada `atlas.cozinha.Cozinha.main`. Edite `resources/fxml/cozinha.fxml` no Scene Builder. A seleção do adaptador e a revisão de falhas seguem o [manual da impressora](../00%20-%20Documentacao%20Geral/Manuais/Impressora.md).
