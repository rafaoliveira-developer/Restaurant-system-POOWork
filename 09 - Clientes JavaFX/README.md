# Clientes JavaFX compartilhados

Abra esta pasta no BlueJ e rode `Build.ps1` para preparar `+libs`. O módulo fornece o cliente HTTP, a conexão MQTT, a sessão visual e a fila compartilhada por Bar e Cozinha. Ele é carregado pelo Desktop e pelos terminais; para executar as interfaces use os pontos de entrada desses módulos.

Abra `resources/atlasfx/login.fxml` no Scene Builder para editar o acesso dos terminais. CSS base em `resources/atlasfx/atlas.css`.
