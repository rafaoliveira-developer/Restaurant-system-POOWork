# Terminal do Bar

Na raiz, execute `Build.ps1` e `& '.\07 - Infraestrutura\Scripts\Run.ps1' -Module Bar`. Use conta BAR e credencial MQTT provisionada para o mesmo código. A fila mostra os itens do Bar, o garçom, a mesa, observações, tempo de espera e estado. Registre início do preparo, pedido pronto ou motivo de falha.

Abra a pasta deste módulo no BlueJ. Ponto de entrada `atlas.bar.Bar.main`. Edite `resources/fxml/bar.fxml` no Scene Builder. A [infraestrutura](../07%20-%20Infraestrutura/README.md) deve estar em execução.
